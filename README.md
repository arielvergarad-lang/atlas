# Atlas — Guías de estudio de punta a punta

Currículos densos y prácticos para aprender desarrollo desde cero hasta producción. Estructura repetible: conceptos con mapas + currículo de libros/cursos por etapas + proyectos reales + plan de estudio.

Cada guía es una página HTML autocontenida (sin dependencias, funcional offline).

## Guías

| # | Guía | Tema |
|---|------|------|
| 1 | [Backend de Punta a Punta](guia/backend-guia.html) | Lenguajes, frameworks, bases de datos, arquitectura, sistemas distribuidos, testing, observabilidad |
| 2 | [Seguridad de Punta a Punta](guia/seguridad-guia.html) | OWASP, criptografía, auth, infraestructura, respuesta a incidentes |
| 3 | [DevOps de Punta a Punta](guia/devops-guia.html) | CI/CD, containers, IaC, observabilidad, SRE |
| 4 | [Front-end de Punta a Punta](guia/frontend-guia.html) | HTML/CSS/JS, React, rendimiento, accesibilidad |
| 5 | [IA aplicada de Punta a Punta](guia/ia-aplicada-guia.html) | ML, LLMs, pipelines, evaluación, agentes |
| 6 | [Arquitectura de la Nube de Punta a Punta](guia/cloud-guia.html) | AWS, diseño de sistemas, costos, serverless |
| 7 | [Carrera + Freelance de Punta a Punta](guia/carrera-guia.html) | Portfolio, entrevistas, clientes, pricing |
| 8 | [Datos y SQL de Punta a Punta](guia/datos-guia.html) | Modelado, consultas, ETL, warehouses |
| 9 | [Fundamentos de CS de Punta a Punta](guia/fundamentos-guia.html) | Estructuras de datos, algoritmos, redes, sistemas |
| 10 | [Recursos y Comunidades](guia/recursos-guia.html) | Dónde aprender, comunidades, certificaciones |

## Uso

Abre [`index.html`](index.html) con cualquier navegador y navega a la guía que quieras. Cada guía funciona completamente offline.
